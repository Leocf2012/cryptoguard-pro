  4. Veja Top Holders → ninguém com mais de 15%?
  5. Veja Origem → veio de compra ou distribuição grátis?

📤 Origem dos Tokens

No Explorador → aba Transfers/Transações:

🟢 Bom sinal:
• Carteira enviou SOL/ETH → recebeu token
• Compra direta na pool de liquidez
🔴 Alerta:
• "Workerput", "Relay", "Merkle" = distribuição automática
• Mesmo valor enviado para 20+ carteiras
• Carteira nova recebeu sem comprar nada

👤 Criador / Dev

🔍 Verifique a carteira que criou o token:

  • • Ainda segura muitos tokens?
  • • Já vendeu/enviou para outras carteiras?
  • • Enviou para várias carteiras ao mesmo tempo?
  • • Renunciou ao contrato (não pode mais controlar)?

👥 Reais vs Falsos

🟢 Comprador Real
  • • Carteira com histórico de transações
  • • Comprou com dinheiro próprio (SOL/ETH)
  • • Não recebeu de "amigo" ou sistema
  • • Valores diferentes, naturais
🔴 Suspeito/Falso
  • • Carteira criada dias/horas atrás
  • • Recebeu token sem comprar nada
  • • Valor idêntico a outras carteiras
  • • Nome de sistema: Proxy, Disperse, Worker

⚠️ Checklist de Riscos

✅ Pode entrar SOMENTE se TODOS forem OK:

  • ✓ RugCheck: Seguro / Sem risco
  • ✓ Liquidez TRAVADA + BLOQUEADA
  • ✓ Criador renunciou ao contrato
  • ✓ Ninguém tem mais de 10-15% do total
  • ✓ Compradores reais, não distribuição
