# 🛡️ CryptoGuard Pro

Scanner profissional de tokens Solana e EVM com dados REAIS via DexScreener + RugCheck + Helius RPC.

### 🚀 O que ele faz
- ✅ Score real de segurança (RugCheck)
- 💰 Market Cap, Liquidez e Volume ao vivo
- 👥 Top Holders e % do Top 10
- 🔒 Verifica se Mint Authority está fechado
- 🔗 Links diretos: Solscan, DexScreener, Birdeye, Pump.fun

### 📱 Como usar
1. Cole o contrato do token
2. Clique em Escanear
3. Confira Score, Holders e Riscos

### 🌐 Deixar no ar
Settings > Pages > Branch: main > Save
Seu link ficará: https://leocf201.github.io/cryptoguard-pro/
